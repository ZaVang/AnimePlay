# 全局主题系统

> 对应 `stores/theme.ts`、`SettingsModal.vue`、`App.vue`。2026-04 新增，原开发计划未列。

## 概述

提供 6 套全局配色主题，通过 CSS 变量驱动全站换肤，选择持久化到 localStorage。在「设置 → 显示设置 → 全局主题」切换。

## 主题列表（`themes`）

| id | 名称 | 图标 | 风格 |
|---|---|---|---|
| `warm` | 暖调浅色 | 🌅 | 米黄色调（**默认**） |
| `flip7` | Flip7 青绿 | 🃏 | 清新青绿，卡牌风 |
| `dark` | 深色霓虹 | 🌃 | 赛博朋克深色 |
| `ocean` | 海洋蓝 | 🌊 | 深邃蓝色 |
| `sakura` | 樱花粉 | 🌸 | 粉色系 |
| `forest` | 森林绿 | 🌲 | 绿色系 |

## 工作机制

每套主题定义一组语义化颜色（`ThemeColors`），分类：

- **背景**：`bgPrimary` / `bgSecondary` / `bgCard` / `bgHeader`
- **文字**：`textPrimary` / `textSecondary` / `textMuted`
- **强调**：`accent` / `accentHover` / `accentLight`
- **边框**：`border` / `borderLight`
- **特殊**：`success` / `warning` / `danger`

`setTheme(id)` 时，`applyThemeToDom` 把每个颜色写成 CSS 变量注入 `:root`，命名规则是 camelCase → kebab-case：例如 `textPrimary` → `--theme-text-primary`。组件通过 `var(--theme-...)` 引用即可随主题变化。

- 持久化：localStorage 键 `app-theme`，store 初始化时 `loadTheme()` 自动恢复。
- 默认：`warm`。

## ⚠️ 关键遗留问题：主题迁移只做了一半

主题系统**定义了完整的文字色变量**（`--theme-text-primary` 等），但**大量组件仍硬编码 `text-white`**（全仓 172 处、46 个文件，如 `PlayerStatus.vue:15`），没有接到主题变量上。

后果：这些 `text-white` 是早期深色主题时代的产物，在默认的浅色「暖调」主题下，标题白字压在米黄色背景上几乎不可读（首页"玩家状态/观看队列"、挑战塔标题、养成标题等大面积泛白）。

**这是当前最高优先级的视觉 bug**。修复方向：把硬编码的 `text-white` / 各种 `text-gray-xxx` 批量替换为 `text-[var(--theme-text-primary)]` 等主题变量。详见 `项目审计报告-2026-06-12.md` 第四节。

## 历史遗留：两套主题概念并存

`settings.ts` 中还有一套旧的 `uiTheme`（经典/赛博朋克/简约）与 `themePresets`、`applyPreset`，已无任何 UI 入口调用，是死配置。真正生效的全局主题是本文描述的 `theme.ts` 这一套。重构时可删除 `settings.ts` 的旧主题残留。
