# 皮肤系统（主题装扮）

> 对应 `assets/skins.css`、`config/skins.ts`、`stores/theme.ts`、`SettingsModal.vue`。
> 2026-04 以「6 套配色主题」初版上线；**S7（2026-06）重构为皮肤令牌系统**，全站 ~770 处硬编码色彩归一到语义令牌，旧「迁移只做一半导致泛白」问题已根治。

## 概述

5 套皮肤装扮，不只换颜色——底纹材质、面板圆角、阴影质感、按钮光效都随皮肤切换。
在「设置 → 显示设置 → 皮肤装扮」选择；选择**随账号存档漫游**（存档协议 v4 的 `appearance.skinId`），换设备登录自动恢复；未登录时使用设备本地缓存（localStorage 键 `app-skin`）。

## 三层架构

```
config/skins.ts        注册表：名称/描述/预览色板/unlock（元数据，无颜色真值）
assets/skins.css       真值：每套皮肤一个 [data-skin] 块（颜色 + 装饰令牌）
stores/theme.ts        状态：切换 <html data-skin> + localStorage；账号同步走存档
```

切换皮肤 = 改 `<html data-skin="...">` 一个属性，CSS 变量级联完成其余一切。
`index.html` 头部有内联防闪脚本：样式生效前先把缓存的皮肤写到 `<html>`，暗色用户首屏不会白闪。
保存时机：设置页调 `userStore.setSkin(id)`（门面应用 + 登录态下触发存档；未登录自动跳过）。

## 令牌（设计规范，新代码必读）

### 颜色令牌 `--c-*`（RGB 三元组，如 `43 168 162`）

| 语义 | Tailwind 类 | 用途 |
|---|---|---|
| app / header | `bg-app` `bg-header` | 页面底 / 顶栏侧栏 |
| surface / surface-2 / elevated | `bg-surface` `bg-surface-2` `bg-elevated` | 面板卡片 / 嵌套·输入·悬停 / 弹窗 |
| ink / ink-2 / ink-3 | `text-ink` `text-ink-2` `text-ink-3` | 主文字 / 次要 / 弱化 |
| on-accent | `text-on-accent` | 强调色底上的文字（午夜/霓虹皮肤是深字！别写死 white） |
| accent / accent-strong / accent-soft | `bg-accent` 等 | 主强调 / 悬停 / 淡底 |
| highlight | `text-highlight` | 次强调（货币数字、UP 标识等） |
| success / warning / danger / info | `text-danger` 等 | 状态色 |
| line / line-2 | `border-line` `border-line-2` | 边框（裸 `border` 默认色已指向 line） |

- Tailwind 透明度修饰符可用：`bg-accent/20`、`bg-surface-2/50`。
- `<style>` 里取色必须包 `rgb()`：`color: rgb(var(--c-ink))`；带透明度 `rgb(var(--c-accent) / 0.2)`。

### 装饰令牌 `--sk-*`（完整 CSS 值）

`--sk-app-bg`（页面底纹/渐变）、`--sk-radius-panel` / `--sk-radius-control`（圆角，Tailwind `rounded-panel` / `rounded-control`）、`--sk-shadow-card` / `--sk-shadow-pop`（阴影，`shadow-card` / `shadow-pop`）、`--sk-glow-accent`（主按钮光效，`shadow-glow`；非霓虹皮肤为透明占位 `0 0 #0000`，保持 shadow 列表合法）。

### 组件类（main.css）

按钮一律选用色阶：`.btn-primary` / `.btn-secondary` / `.btn-danger` / `.btn-ghost`（自含 padding/圆角/字重/disabled 态）；面板 `.app-panel`；输入框 `.input-control`。

### 跨皮肤固定色（刻意不随皮肤）

稀有度配色（UR红/HR紫/SSR金/SR蓝/R绿/N灰）、战斗资源识别色（TP 蓝、HP 红等）、卡面图片上的黑色遮罩压片与其上白字、弹窗黑遮罩 `bg-black/NN`。这些是游戏识别色/物理遮罩，**不要**换成语义令牌。

## 新增一套皮肤（三处同改）

1. `assets/skins.css` 加一个 `[data-skin='xxx']` 块（全部 `--c-*` + `--sk-*` 令牌）；
2. `config/skins.ts` 注册表加条目（含预览色板近似值）；
3. 本文档表格加一行。
