# 留存系统

> evolution 第 1–4 / 7 轮新增（2026-06）：给「玩法齐全但没动机」的产品装上每日回访与长期目标。
> 对应 `stores/{daily,achievements,codex}.ts` + `config/{dailyTasks,achievements,codexUnlock}.ts` + `stores/onboarding.ts` + `components/{DailyTasksPanel,CodexPanel,ShareCard,AnimeTimeline,OnboardingGuide}.vue` 等。

## 每日 / 每周任务 + 连续登录（`stores/daily.ts`）

- **每日任务（5 条）**：抽卡 / 赢对战 / 收观看 / 养成互动 / **玩小游戏**（`config/dailyTasks.ts` 的 `DAILY_TASKS`）。命中现有玩法成功点，做满领奖。跨天读时归零（复用 shop 的 `todayKey` 模式，不存定时器）。
- **每周任务（4 条）**：抽 20 / 赢 5 / 收 7 / 玩 10 局小游戏。`markProgress(type)` 同时遍历日+周任务，**埋点零重复**。weekKey（ISO 周）跨周归零。
- **连续登录递增**：`loginStreak` 昨日登录过则 +1、断签归 1；登录奖励按连签档递增（`LOGIN_STREAK_REWARDS`：第 1/3/7/14/30 天越往后越厚）。
- 主页 `DailyTasksPanel.vue` 展示。奖励只走 `profile.earn`。

## 成就系统（`stores/achievements.ts` + `config/achievements.ts`）

事件驱动：玩法成功点调 `check(event, payload)`，按 event 分发到各条 `condition`，解锁发徽章 + 一次性奖励。**21 条成就**覆盖 7 类事件：`gacha / battleWin / watch / nurture / guess / tower / codex / minigame`。只持久化已解锁 id（计数器会话级，靠已解锁 id 幂等）。卡牌收藏「成就」tab 展示成就墙。

## 图鉴：完成度 + 里程碑 + 定向解锁（`stores/codex.ts` + `config/codexUnlock.ts`）

卡牌收藏「图鉴」tab：

- **完成度**：各稀有度 X/总数（从 `collection` ⊆ `gameDataStore` 全量**纯派生**，总数一律 `.length` 不硬编码）+ 未拥有灰位（复用 VirtualGrid）。
- **收集里程碑**：静态里程碑（收 50/100/300/500 角色、集齐 UR…）达成可领奖，已领 id 进存档。
- **定向解锁（经济出口）**：灰位未拥有卡可花知识点直接解锁入库（`config/codexUnlock.ts` 定价——UR 远贵、阶梯递增、明显高于分解回收，不架空抽卡）。解锁流：`spend('knowledgePoints')` 成功才 `addCard`。

## 真实数据可视化

- **卡详情真实元数据**：CardDetailModal 展示 anime 真实评分/排名/放送年、character 作品数/人气（`types/card.ts` 显式可选字段，缺失 v-if 守卫）。
- **番剧年表**（`components/AnimeTimeline.vue`，收藏「年表」tab）：已拥有动画按真实放送年（`date`）分组成时间轴，纯派生。

## 新人 onboarding + 传播

- **FTUE 点火**（`stores/onboarding.ts`，localStorage 触发不进存档）：首登 4 步引导遮罩（指向每日任务/抽卡/收藏/对战，可跳过）+ 首抽庆祝 + 空态 CTA。
- **可分享 Wrapped 成绩卡**（`components/ShareCard.vue`）：收藏页一键生成可下载炫耀图（标准 Canvas `toBlob`+`a.download`，不引 html2canvas），聚合图鉴完成度/等级/成就/塔进度/真实数据。聚合逻辑是纯函数 `wrapped/buildWrappedStats.ts`。

## 跨系统红点（`App.vue`）

侧边导航对「有奖可领/有新内容」的模块加红点角标——主页（每日/周任务或登录奖励可领）、卡牌收藏（图鉴里程碑达成未领 / 成就新解锁未读）、小游戏（有奖可领）。daily/codex 可领态纯派生；成就「已读」用 localStorage（`stores/achievementsRead.ts`，设备级不升 schema）。

## 存档

留存数据随协议演进：v3 猜角色最高分、v6 每日任务/图鉴里程碑/成就、v7 周任务+连签。成就只存已解锁 id；图鉴里程碑存已领 id；onboarding/成就已读用 localStorage 不进存档。
