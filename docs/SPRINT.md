# 极简冷淡风 (Clinical & Industrial) UI 设计重构方案

本项目原本是一个基于“动画卡牌”的游戏，容易陷入色彩饱和度过高、特效过分“原神/二次元光环”的刻板印象中。为了契合《明日方舟》（工业机能风、末日战术板）或《重返未来：1999》（神秘学复古、档案整理室）的美术风格，我们在**核心逻辑和组件树保持不变**的前提下，通过重写 Tailwind CSS 预设、全局 CSS 变量以及部分 CSS 动画，全面提升产品的“高级感”与“冷淡感”。

---

## 全局美学基调 (Aesthetic Direction)

### 1. 字体排版 (Typography)
*   **废弃圆润字体：** 杜绝使用任何如 Comic Sans 或圆体字。
*   **多语种混合排版：**
    *   **UI 标签与数字：** 强制使用高科技感的等宽字体，如 **`JetBrains Mono`**, `Roboto Mono` 或 `Space Mono`。数字展示应带有前导零（如 `LV. 05` 代替 `等级 5`）。
    *   **正文排版：** 采用 `Noto Sans SC` 或 `Inter`。字重只用极细（200/300）和极粗（700/800）形成强烈对比。
*   **装饰性英文单词：** 在主要 UI 组件背后添加大写的极简英文水印（如 `STORAGE`, `RECRUITMENT`, `COMBAT_LOG`），透明度设为 5%-10%，增加画面层次感。

### 2. 色彩与主题 (Colors & Theme)
*   **背景色 (Backgrounds)：** 冷黑 `#121212` 或暗深蓝灰色 `#171A21` 作为主色底；大块区域也可以使用极简白 `#F4F4F4` 配合纯黑文字，制造“机密文档”感。
*   **强调色 (Accents)：** 反对彩虹色。仅保留：
    *   **警示黄 (Warning Yellow):** `#FACC15`（用于高稀有度、警告、执行按钮）
    *   **医疗蓝 (Clinical Blue):** `#38BDF8`（用于普通状态、护盾、我方信息）
    *   **危险红 (Danger Red):** `#EF4444`（用于敌方、掉血、负面状态）
*   **边框与形状：** 禁用大圆角（不要用 `rounded-lg` 或 `rounded-xl`）。全部改用**直角 (`rounded-none`) 或极小圆角 (`rounded-sm`)**，外加 1px 细线边框（`border-zinc-700` 或半透明的白）。

### 3. 排版理念与动效 (Spatial & Motion)
*   强调**不对称性**和**切角**（使用 CSS `clip-path` 创建斜切的按钮或容器边缘）。
*   动画节奏**干脆利落**：抛弃软绵绵的 ease-in-out，使用阶跃动画 (steps) 或起步极快、收尾极慢的贝塞尔曲线（如 `cubic-bezier(0.19, 1, 0.22, 1)`）。加入打字机效果、扫描线 (scanlines)、轻微的文字闪烁 (glitch)。

## 各 Tab 界面的重塑方案

### 1. 主页 (HomeView) —— 【战术看板室】
不应像个传统的游戏大厅，而应像个指挥官的桌面控制台。
*   **PlayerStatus (玩家状态):** 将数值设计成仪表盘或者发光的代码片段。如 `[ UID: 8129 ] | CL_LEVEL_41`，边框使用带倒角 (Chamfer) 的细框线。
*   **WatchQueue / ActivityLog:** 设计为类似终端输出 (Terminal Feed) 的效果。黑底绿字或黑底白字，等宽字体，每条日志左侧带有具体到微秒的时间戳 `[13:42:01.004] >`。
*   **CollectionPreview:** 将角色卡片模糊化，辅以“分析中...”的细线条进度条，不要直接抛出花哨的插画。

### 2. 抽卡系统 (GachaView) —— 【人员招募/档案解密】
杜绝常见的“抽卡发光球体/发光石头”和“星星”。
*   **界面 UI:** 整体像是一个带有防伪水印和杂色印花的机密档案解密界面。采用高对比度黑白红色调。
*   **抽卡操作:** 按下“招募”按钮时不是闪瞎眼的白光，而是类似于**解密进度条/磁带转动/印章盖下 (APPROVED / CLASSIFIED)** 的生硬动画。
*   **高稀有度表现:** 不要用金光闪闪的星光。屏幕边缘出现 CRT 显示器的横向干扰纹 (Glitch)，黑底上突然划过一道锐利的亮黄或深红切割线，浮现出角色代号，最后黑白照片切换为全彩。

### 3. 卡牌收藏 (CollectionsView) —— 【机密数据库】
*   **列表视图:** 不用花哨的卡牌背板，卡片边框采用 1px 实线框。未拥有的卡片不是单纯变暗，而是采用大块的 `[ DATA EXPUNGED ]` 文字遮盖和斜线填充条纹背景 (Diagonal stripes)。
*   **卡详情 (CardDetailModal):** 左侧大图，右侧数据。数据的排列类似体检报告或实验室档案。技能描述使用带编号的项目符号，如 `◇ SKILL.01:`。属性条不是普通的圆角进度条，而是分块的网格指示器（用实心方格 `■■■□□` 替代条状圆润的槽）。

### 4. 宅理论战 (BattleView) —— 【逻辑冲突推演】
这是变化最大、最适合做冷淡风格的地方，要有战术指挥感。
*   **TopicBiasBar (议题偏向条):** 不要用平滑渐变的血条。改成类似**心电图 (ECG)**、**音波频谱仪**或**拉锯战网格**，通过断断续续的方块或跃动的冷色调线条来表示当前的局势偏向。
*   **BattleLog:** 左侧彻底化身为黑客执行攻击指令的代码控制台，每一次对撞都是一行新的 `Execute: DEFENSE_PROTOCOL`，带有细微的打字机特效。
*   **操作区 (Action Area):** “结束回合”按钮改成带有斜切角的工业级按键面板，配有提示性条纹安全线（黄黑相间的 warning line），外侧配以英文大写 `[ END TURN ]`。
*   **打击感:** 伤害及回复数值特效使用高亮等宽数字浮现，屏幕采用轻微位移震动 (CSS Shake) 加 RGB 通道分离的故障频闪 (Glitch Out) 来替代传统的满屏红光。

## UI/UX Pro Max 深度优化 (进阶重构阶段)

目前的 UI 仍然存在严重的“风格割裂感”。为了彻底消除“AI 生成感”并达成极致的沉浸体验，我们将进入 **Pro Max 级重构阶段**。

### 核心设计纲领：Cyberpunk Industrial Tactical Terminal
*   **形态：** 彻底终结所有 `rounded-lg`，代之以凌厉的工业斜切角 (`clip-chamfer`)。
*   **配色：** 废除 `bg-white` 和泛用灰色，严格锁定 `industrial` 和 `clinical` 专业色盘。
*   **排版：** 核心数据展示（Lv、Cost、Status）强制单行等宽 (Monospace) 化。

### 待执行重构清单

#### 1. 核心卡牌重构 (Data Slate 化)
*   **AnimeCard & CharacterCard:**
    *   移除 `bg-white` 样式的白色背景。
    *   采用 `bg-industrial-800` (深色工业底) + `border-industrial-600` (战术边框)。
    *   将圆型的 Cost Gem 重新设计为带斜切边的多边形容器 (Tactical Poly-GEM)。

#### 2. 首页数据看板重构 (Dashboard 化)
*   **HomeView:** 优化各 Block 之间的像素级对齐，移除多余留白。
*   **PlayerStatus:**
    *   重构经验条为段落式能量槽 (Segmented Energy Bar)。
    *   玩家数值面板增加装饰性数据斜杠 (如 `// STATUS //`)。
*   **通用面板 (ActivityLog / ViewingStats / WatchQueue):**
    *   统一面板 Header 样式，增加状态指示灯小装饰。

#### 3. 全局动效与底层打磨
*   **main.css:**
    *   引入 `Datapad Reveal` 故障入场动画。
    *   为交互按钮增加类似“机械按键”触发的微动效。
    *   所有卡牌悬停效果增加轻微的 RGB Offset 偏移特效。
