# 角色养成系统

> 入口：`/homestead?tab=characters`（基地 hub 的角色面板）。旧 `/nurture` 保留为兼容入口，会重定向到基地角色面板。完整操作仍由 `views/NurtureView.vue` 提供。

现行养成是 S13 基地闭环的一部分：家园挂机和挑战塔奖励提供角色经验，角色升级获得五维随机加点，装备进一步补强战力；好感用于关系仪表与里程碑奖励，不直接进战斗公式。

## 基地 hub 中的位置

1. `家园`：入住角色获得离线经验、好感和知识点。
2. `角色`：查看并操作等级、好感、五维、装备和小队战技能。
3. `编队`：把已培养的 HR/UR 角色放入 5 人挑战塔阵容。
4. `探索/战斗`：用横板半自动战斗验证成长，并把奖励回流。

## 养成数据结构

`CharacterNurtureData` 已瘦身为两条主轴：

| 字段 | 含义 |
|---|---|
| `level` / `experience` / `totalExperience` | 角色等级与经验 |
| `statPoints` | 升级随机分配到 HP/ATK/DEF/SP/SPD 的五维加点 |
| `affection` | 好感度，驱动关系称号与里程碑 |
| `claimedBondMilestones` | 已领取的好感里程碑 |
| `lastInteraction` | 最近互动/成长时间 |

旧的训练、对话、礼物、心情、四维属性和百分比战斗强化不再是现行机制。

## 等级与五维

- 最大等级为 `MAX_CHARACTER_LEVEL`。
- 经验曲线与升级规则在 `engine/nurture/rules.ts`。
- 每次升级会通过注入式 RNG 把点数分配到 HP、ATK、DEF、SP、SPD。
- 实战属性由 `generateBattleStats(base, statPoints, equipBonus)` 计算。

角色面板展示每一维的基础值、升级加点、装备加成和最终值；编队和挑战塔使用同一口径计算战力。

## 好感与里程碑

- 好感来自家园离线收益与战斗/养成相关动作。
- 好感称号和里程碑配置在 `config/nurture.ts`。
- 达成里程碑后可领取知识点奖励。
- 好感不直接提高挑战塔战力，避免和等级/装备路径混淆。

## 装备联动

角色有 3 个装备槽：武器、防具、支援。

| 槽位 | 作用 |
|---|---|
| 武器 | 偏向攻击或技能输出加成 |
| 防具 | 偏向生命、防御等生存加成 |
| 支援 | 偏向速度、技能或家园收益词条 |

装备实例在 `equipment` 域持久化；配装后通过 `equipmentStore.resolveEquipBonus(characterId)` 同步影响角色面板、编队战力和挑战塔实战。

## 操作入口

- `角色面板`顶部提供当前角色的五维、装备和小队战技能摘要。
- 面板下方保留 `NurtureView` 的完整角色列表、补习、配装、背包和里程碑领取体验。
- `/nurture` 旧链接不会 404，会进入基地角色面板。

## 关键文件

- `frontend-vue/src/views/HomesteadHubView.vue` — 基地角色面板与技能摘要
- `frontend-vue/src/views/NurtureView.vue` — 角色养成、补习、配装、背包和里程碑
- `frontend-vue/src/engine/nurture/rules.ts` — 经验、等级、随机加点纯规则
- `frontend-vue/src/config/nurture.ts` — 养成数值、五维展示、好感里程碑
- `frontend-vue/src/stores/nurture.ts` — 角色养成域状态
- `frontend-vue/src/stores/equipment.ts` — 装备域状态与加成解析
- `frontend-vue/src/engine/squad/combat.ts` — 战力与实战属性计算
