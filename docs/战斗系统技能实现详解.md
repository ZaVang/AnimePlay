# 战斗系统技能实现详解

## 概述

本文档详细介绍了 bangumi 项目中战斗系统的架构实现，特别是角色技能的注册机制、依赖注入系统和各个核心组件的功能。整个系统基于 Vue 3 + TypeScript，采用了先进的依赖注入模式和模块化设计。

## 系统架构总览

### 核心组件关系图

```
BattleView.vue (战斗主界面)
├── 依赖注入系统 (/src/core/di/)
│   ├── injection-keys.ts - 注入键定义
│   ├── registry.ts - 系统注册表
│   └── composables.ts - 组合式函数
├── 战斗系统 (/src/core/systems/)
│   ├── SkillSystem.ts - 技能系统核心
│   ├── PersistentEffectSystem.ts - 持续效果系统
│   ├── InteractionSystem.ts - 复杂交互系统
│   └── DialogueSystem.ts - 对话系统
├── 技能实现 (/src/skills/)
│   ├── registry.ts - 技能注册表
│   ├── utils.ts - 技能工具函数
│   └── characters/ - 64个角色技能实现
└── 战斗控制器 (/src/core/battle/)
    ├── BattleController.ts - 战斗流程控制
    └── TurnManager.ts - 回合管理
```

  for (const bonus of this.bonuses.values()) {

      // 检查卡牌类型匹配

### 6. 技能注册系统 (`frontend-vue/src/skills/registry.ts`)

**功能：** 自动导入和注册所有角色技能，提供统一的技能执行接口

#### 核心机制：

##### 自动导入技能 (第17-38行)
```typescript
const characterModules = import.meta.glob('./characters/*.ts', {
  eager: true
}) as Record<string, any>;

function createSkillRegistry(): Record<string, SkillEffect> {
  const registry: Record<string, SkillEffect> = {};

  // 处理所有角色模块
  for (const [path, module] of Object.entries(characterModules)) {
    // 查找以 "Skills" 结尾的导出
    for (const [exportName, exportValue] of Object.entries(module)) {
      if (exportName.endsWith('Skills') && typeof exportValue === 'object') {
        Object.assign(registry, exportValue);
      }
    }
  }
  return registry;
}
```

#### 主要函数：

##### `runEffect()` - 执行技能效果 (第51-64行)
```typescript
export async function runEffect(effectId: string, context: EffectContext): Promise<void> {
  const effect = skillEffects[effectId];
  if (!effect) {
    console.warn(`技能效果 "${effectId}" 未找到`);
    return;
  }

  try {
    await effect(context);
  } catch (error) {
    console.error(`执行技能效果 "${effectId}" 时出错:`, error);
  }
}
```

##### `getRegistryInfo()` - 获取注册信息 (第100-107行)
- 返回模块数量、路径、技能数量等调试信息
- 用于开发时检查技能注册状态

makeDefenseDecision(defender: PlayerState, clashInfo: ClashInfo) {
  const affordableCards = defender.hand.filter((card: AnimeCard) => (card.cost || 0) <= defender.tp);

  // 选择最佳防御卡牌：优先考虑强度vs费用比
  const bestDefenseCard = affordableCards.reduce((best: AnimeCard, card: AnimeCard) => {
    const cardValue = (card.points || 1) / Math.max(card.cost || 1, 1);
    const bestValue = (best.points || 1) / Math.max(best.cost || 1, 1);
    return cardValue > bestValue ? card : best;
  });

  // 智能防御风格选择
  const shouldRebuttal = canAffordRebuttal && attackerStrength >= 3;
  const defenseStyle = shouldRebuttal && Math.random() < 0.7 ? '反驳' : '赞同';
}

## registry.ts 的不同方法详解

### `systemRegistry` 类的所有方法：

#### 核心注册方法：
1. **`registerSystems(systems)`** - 注册三大战斗系统
   - 参数：包含 interaction、persistent、dialogue 系统的对象
   - 功能：一次性注册所有系统实例

2. **`getPersistentEffectSystem()`** - 获取持续效果系统
   - 返回：PersistentEffectSystem 实例
   - 异常：如果未注册则抛出错误

3. **`getInteractionSystem()`** - 获取交互系统
   - 返回：InteractionSystem 实例
   - 异常：如果未注册则抛出错误

4. **`getDialogueSystem()`** - 获取对话系统
   - 返回：DialogueSystem 实例
   - 异常：如果未注册则抛出错误

5. **`clear()`** - 清理所有系统
   - 功能：将所有系统实例设为 undefined
   - 用途：组件卸载时清理资源

### 使用模式：

#### 在 BattleView.vue 中的注册：
```typescript
systemRegistry.registerSystems({
  interaction: interactionSystem,
  persistent: persistentSystem,
  dialogue: dialogueSystem
});
```

#### 在技能中的使用：
```typescript
const persistentSystem = systemRegistry.getPersistentEffectSystem();
persistentSystem.addEffect({...});
```

#### 在系统退出时的清理：
```typescript
onBeforeUnmount(() => {
  systemRegistry.clear();
});
```

## 总结

该战斗系统采用了现代化的软件设计模式：

1. **依赖注入** - 解耦组件依赖，提高可测试性
2. **工厂模式** - 灵活创建带依赖的控制器实例
3. **观察者模式** - 事件驱动的技能触发机制
4. **策略模式** - 可扩展的效果处理系统
5. **自动化注册** - 减少手动配置，支持动态扩展

整个系统支持 64 个角色的 128 个技能，每个技能都可以有复杂的交互逻辑、持续效果和条件判断。通过模块化设计和类型安全的接口，系统具有良好的可维护性和扩展性。
