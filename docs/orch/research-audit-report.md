# Product Research Audit Report — Iteration 1

## Executive Summary

当前设计基于 4 个关键假设：家园是角色展示空间；挂机收益是回归补充；装备是战力数值；不升存档优先。最大研究发现是：家园真正要解决的不是“展示角色”，而是“让玩家的收藏被重新安置成一个每天可回来的生活系统”。最有价值的突破方向是把装备效果接入家园收益，让战斗养成和陪伴养成第一次交叉。

## Phase 1: 核心假设质疑

- 假设清单：
  - 家园 = 可爱场景。可质疑：二游家园通常也是资源与羁绊 hub。
  - 入住 = 选择最多 6 人。成立，但缺少岗位/设施语义。
  - 离线收益 = flat exp/affection + rarity KP。成立，但没有可优化空间。
  - 装备 = 五维加成。可质疑：装备也可以承载家园/养成效果。
  - 不升存档 = 本轮边界。成立，应优先做派生系统。
- 关键假设深挖：若家园不是展示页，而是基地页，第一屏必须展示产出、设施和角色状态。若装备不是纯战力，目录项需要能被比较的效果字段。
- 被隐喻限制的地方：当前“广场漫步”隐喻让角色很活，但没解释家园如何改变玩家策略。

## Phase 2: 相邻领域研究

- 家园/基地系统：常见模式是派驻角色、设施产出、舒适度或恢复、角色互动。
- 装备/词条系统：常见模式是固定槽、主属性/副属性、套装或效果标签、比较预览。
- 放置收益系统：核心是可预测产率、离线封顶、防止盖过主动玩法。
- 可迁移模式：
  - 派生舒适度：不用新存档，用入住角色和装备计算。
  - 设施三分法：训练区（经验）、休息区（好感）、资料室（KP）。
  - 装备效果标签：让同稀有度同槽有不同用途。

## Phase 3: 逻辑完备性

- 概念体系：角色收集 → 入住家园 → 离线收益；装备收集 → 配装 → 战力。缺口在“装备对家园是否有意义”。
- 极端场景：
  - 0 入住：应显示 0 产率和管理入口。
  - 6 入住无装备：仍有基础产出。
  - 6 入住全 UR 装备：有加成但应封顶，避免挂机盖过主动玩法。
- 操作缺口：玩家无法判断家园当前效率，也无法知道装备效果是否生效。
- 演化瓶颈：若马上做家具摆放，需要新库存/坐标/舒适度存档；本轮应避免。

## Phase 4: 替代设计提案

- 方案 A：纯 UI 仪表，不改收益。低风险但效果“假”，玩家很快会发现无策略。
- 方案 B：装备效果影响家园收益。本轮推荐，真实闭环且不升存档。
- 方案 C：家具/房间编辑器。长期潜力高，但存档和 UI 成本大。
- 概念重组：把家园看作“角色基地”，装备看作“角色携带的设施贡献”，让已有 inventory/equipped 域自然承载新玩法。
- 灵感炸弹：
  - Bangumi 资料室：看过/收藏越多，资料室主题产率不同。
  - 角色来访事件：未入住但已收藏角色随机来访，触发轻量好感/知识事件。

## Prioritized Research Directions

- High-impact, Low-effort：装备效果接入家园离线收益；家园页显示派生产率。
- High-impact, Low-effort：装备目录扩容并让掉落从候选池随机。
- High-impact, High-effort：家具舒适度与房间摆放。
- Thought-provoking：按番剧题材组成家园主题羁绊。
- Wild idea：把“正在追番”变成家园里的放映室排片。
