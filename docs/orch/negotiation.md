## 〇、核心分歧裁决：S15-T4 = pity 还是碎片？

- **体验官（product-audit）**：强推**碎片定向兑换**（Phase3 主张），理由=同解「定向补槽难 / 毕业断流 / 重复件转化」三洞，更贴 968 番 + 名梗装备的收集灵魂；pity 可做轻量「空掷保底」互补。
- **进化策略师（evolution-audit）**：强推**pity（成败命门第一条）**，理由=纯确定性、复用自家 gachaStore 保底范式、零新货币/UI 表面、改动面与退化风险都远小于碎片（碎片 = 小 sink 重体验，2~3 倍改动面）。
- **研究员（research-audit）**：首选**碎片 A2（分解→碎片→定向）+ 顺手叠 A3 去重池**，最激进；但也备案 pity A1（必做槽位维度）。

**裁决 = pity（选项 a），采纳进化策略师主张。** 决定性因素：
1. **本 Sprint 收官轮** —— 收官不宜引入「重体验、新货币口径、新兑换 UI、新发放埋点」的碎片方案（改动面 2~3 倍，退化/半迁移风险高）。
2. **pity 复用项目自家已验证范式**（gachaStore PityState）+ 持久化落点已被 Scout/研究员钉死（`TowerProgress` 扁平字段复用 v20），存档协议干净、测试范式现成（`equipmentSource.test.ts` 序列 RNG）。
3. **直接对应 SPRINT 主清单 S15-T4 选项 (a)**，无歧义。
4. 碎片方案价值确实更高（到 defId 粒度 + 分解闭环 + 图鉴集邮），但属**独立轮次工程量** → **全标 backlog**，不在收官轮硬塞。
