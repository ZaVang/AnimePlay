## 待完成任务（按依赖顺序）

   - 目标：把养成模型砍成"等级（固定初始五维 + 每升一级随机加点）+ 好感（关系仪表/里程碑，不接战力）"两轴，删除训练/强化/对话/礼物等已废维度，引擎新增可复现的随机加点纯函数。
   - 依赖：无（其余任务均建立在本任务的瘦身模型之上）。
   - 验收：类型检查 0 错误；养成引擎测试覆盖加点制——升级时把固定点数随机分配到 5 个战斗维，注入 RNG 可复现；家园挂机与挑战塔结算依赖的加经验/加好感入口仍可用；新增"带塔参战涨好感"与"补习花知识点换经验（走货币 spend 出口）"两个入口。

2. **C1-T2：战力公式改纯加法**
   - 目标：战力由"最终某围 = base + 加点 + 装备加成"纯加法得出，去掉旧的属性百分比/强化乘算；本阶段装备加成恒为 0（空占位）。
   - 依赖：C1-T1（依赖瘦身后的 statPoints 字段）。
   - 验收：类型检查 0 错误；战力计算测试覆盖新纯加法公式并通过；阵容/塔战调用改用新签名传入加点与（恒 0 的）装备加成；塔战结算后给参战角色涨好感，且既有加经验入口保留可用。

3. **C1-T3：删旧养成 UI + 角色页重写（变体 A 游戏化角色面板 + 软上限条）**
   - 目标：删除训练/互动/对话三组旧养成组件及其测试与引用；养成页重写为"游戏化角色详情面板"——角色列表 + 选中角色（立绘、等级/经验进度、好感进度与里程碑称号、五维数值面板含 base/加点两段与软上限参考条、3 个装备空槽占位、补习入口）；好感里程碑分 6 档（阈值/一次性知识点奖励/称号）可领取且已领状态持久化。
   - 依赖：C1-T1、C1-T2（消费瘦身模型与新战力字段）。
   - 验收：类型检查 0 错误；生产构建通过；养成页不再引用任何已删组件或已删字段；软上限参考值与里程碑配置集中可调；五维条按"值/参考"填充、超出满条带 MAX 标记；里程碑奖励经货币 earn 出口发放，已领状态走存档三处同改（若需新字段）；颜色全走皮肤语义令牌（禁 text-white 压浅底、禁动态拼色、禁未定义令牌）。

4. **C1-T4：存档 v14 迁移 + 收口**
   - 目标：存档协议升至 v14——schema 收入瘦身后的养成模型 + 新增"空"装备域占位；提供 v13→v14 迁移（丢弃已删字段、保留等级/好感两轴、补 statPoints 与装备域缺省）；新增装备 store 接入存档装配；迁移/往返测试与文档版本号同步更新。
   - 依赖：C1-T1（schema 收入的字段形状由 T1 定型）。
   - 验收：类型检查 0 错误；测试全绿（含 v14 迁移与往返：旧训练字段被丢、两轴保留、statPoints/装备域缺省补全）；生产构建通过；新增存档字段满足"三处同改"（schema + 迁移 + 装配器）并配迁移/往返测试；家园挂机/挑战塔依赖的现有加经验/加好感入口未被误伤；文档版本沿革补一行 v14。

## 相关陷阱（从 pitfalls.md 筛选）

- **[engine 纯净]** `src/engine/` 零 Vue/Pinia/DOM/fetch/localStorage/`Math.random`。加点制随机分配纯函数的随机源**必须注入**，不得在 engine 内直接调 `Math.random()`（影响 C1-T1）。
- **[依赖只向下]** `views → components → stores → engine`，下层不 import 上层（影响 C1-T1/T2/T3）。
- **[存档三处同改 + 不破往返]** 新增/变更存档字段必须 schema + migrations + 装配器三处同改并补迁移测试（旧档缺省值），且不破坏现有往返保真测试；版本号权威在 `schema.ts` 的 `SAVE_VERSION`，文档只指向不复述（影响 C1-T4，现 13→14）。
- **[别误伤现有入口]** 家园挂机用的加经验/加好感入口与挑战塔结算用的加经验入口必须保留可用——瘦身删 action 时勿连带删除（架构铁律明文，影响 C1-T1/T2/T4）。
- **[货币只走出口]** 补习花费走 `profile.spend`、里程碑奖励走 `profile.earn`，不绕过货币门面（影响 C1-T1/T3）。
- **[颜色铁律 / 未定义令牌双形态]** 界面色用语义类或 `rgb(var(--c-*))`；禁 `text-white` 压浅底、禁动态拼色、禁未定义令牌。审色两种 grep 都要跑：scoped CSS 的 `var(--c-ink-soft)`（未定义变量）与模板的 `text-ink-soft`（未定义工具类）；真令牌是 `--c-line`/`--c-ink-2`/`--c-ink-3` 等；稀有度渐变/立绘识别色/图片压片白字是固定例外（影响 C1-T3）。
- **[硬色连根拔 / 整函数重写]** 养成簇曾有"半语义半硬色"的 partial-migration 复发坑——重写角色页时整函数走语义映射，别逐处 grep-replace 留半硬色（影响 C1-T3）。
- **[setTimeout 假安全]** 组件内所有 setTimeout/setInterval 必须登记并在 onUnmounted 清除（"有 onUnmounted"≠"都登记了"，NurtureActions 曾漏一个）——重写角色页若引入计时器须登记清除（影响 C1-T3）。
- **[测试纪律]** 测试用 `npm run test`（vitest）；**不要跑 `npm run lint`/`--fix`**（会全仓重排），单文件用 `npx eslint <path>`。删训练测试导致总数下降是预期的，但新增 statPoints/combat/v14 迁移测试不得低于"既有数量减去删掉的训练测试"（影响全部任务）。
- **[后端自检环境]** 回归基线 `backend/test_security.py` 用 `./.venv/Scripts/python.exe` 跑（系统 python 无 Flask 依赖）；C1 不碰后端，期望 exit 0 全 PASS（影响验收）。
- **[JSDoc 别写 Tailwind opacity]** `bg-*/20` 这类含 `*/` 的字面量写进块注释会提前闭合注释（影响 C1-T3 角色页若写带 opacity 的注释）。
