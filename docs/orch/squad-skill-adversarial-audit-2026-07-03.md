# 小队战技能「对抗性审计」报告（2026-07-03）

> **一句话结论**：全 318 出战角色的技能**在战斗中真实实装**（引擎逐类型执行，0 克隆、0 非法效果、能量/冷却/dot 全在合理带），三大问题的答案是——**① 实装：是，但有 4 类"静默空过/反向"陷阱**；**② 名字：绝大多数贴合，但查出 ~13 处跨角色/跨作品串名（客观错误）+ 8 处偷懒占位名 + 4 处旗舰重名**；**③ 数值：技能数值内部大体自洽，但有 17 条 0.45 近上限被动的失衡簇；另有 ~49 个 SSR 底板属性异常（属数据层 `all_cards.json`，非技能配置）**。

> **触发**：完成全 SSR+HR+UR 技能设计与实装后，用户要求从第一性原理做对抗性全面复检。
>
> **方法（ground truth，非纸面读配置）**：
> 1. 用**真实装配逻辑** `getSquadSkillKitForCharacter` 跑遍线上服务名单（`data/selected_character/all_cards.json`，318 人）→ dump 出玩家实际会看到的最终技能（名/target/effects/描述）。
> 2. 把**引擎真实语义**（读 `engine/squad/effects.ts` + `timedBattle.ts` + `targeting.ts` + `formulas.ts`）编码成确定性静态分析器，跑遍 318 kit——抓"是否实装/数值越界/反向目标/静默空过"。
> 3. 40 个 subagent 的**对抗性工作流**（20 批 × 逐批审计 + 逐批对抗验证 + 遗漏二刷）覆盖全 318 的"名字契合 / 数值合理 / 效果契合角色幻想"主观轴，每条 finding 都过一次反驳验证。
> 4. 交叉核对：确定性层与工作流层互为佐证，并复核工作流自身的误报（见 §A4、§附录）。
>
> 证据文件：`scratchpad/kits_dump.json`（318 最终 kit）、`mech_findings.json`（确定性）、`subj_findings.json`（工作流 85 条）、`analyze.py`（分析器）。

## 0. 引擎实装事实（判据来源）

这些是从引擎源码读出的**地面真值**，后续所有"是否实装/数值是否合理"都以此为尺：

| 事实 | 出处 | 对设计的含义 |
|---|---|---|
| 引擎逐类型执行 `damage/heal/shield/applyStatus/cleanse/energyGain/dispel/revive/execute` | `effects.ts:406-500` | 所有效果类型都**真跑**，无播报式假实现 |
| **被动开场 t=0 只施加一次**，持续整场 | `timedBattle.ts:333-339` | 被动放 `heal/revive/execute/cleanse/dispel` = **空过**（满血/无人倒下/无状态可净化）|
| dot/hot 的 amount 是**每跳固定点数**且 `Math.floor` | `timedBattle.ts:193` | amount<1 → 归 0 → 静默失效 |
| ratio 型状态（atk/def/sp±、haste/slow/critRateUp）amount 是**分数**，实战按来源累加后 clamp 到 ~0.5–0.6 | `effects.ts:35-57` | amount>1 = 误当固定值；0.45 已近上限 |
| **taunt = 让"对手方"的单体攻击改打被嘲讽者** | `targeting.ts:81-98` | taunt→自己/队友 = 拉仇恨（经典坦克）；taunt→敌人 = **逼我方集火那个敌人**（不是"激怒敌人打我"）|
| 大招能量上限 1000，`energyCost` 全 = 1000 | `timedBattle.ts` | 无不可释放大招 |
| 描述由 `describeSquadSkill` 从 effects **派生**（含 `Math.round(ms/1000)秒`）| `squadSkillKits.ts:166-217` | 描述与效果**不可能真背离**；"描述秒数≠数据"多是取整假象 |

确定性层总判：**0 克隆、0 非法效果、0 不可释放大招、0 dot/hot 空砍、0 误伤友军/资敌**（除惠惠的**有意**自我控制）。实装底子是干净的。

## A. 实装 / 机制陷阱（回答问题 ③）

### A1. 🔴 P0 — 反向嘲讽（inverted taunt）：~17 个坦克的护盾在保护"没人打的自己"

**这是本次审计最大的系统性问题**，确定性层与工作流层**双重独立确认**。

`targeting.ts` 里 taunt 的语义是"让**对手方**的单体攻击转打被嘲讽的单位"。所以：
- taunt→**自己/队友** = 敌人被迫打我 = 经典拉仇恨坦克 ✅
- taunt→**敌人** = **我方**被迫集火那个敌人，**并不会**让敌人来打我 ❌

有 **21 个技能槽（17 个角色）把 taunt 施加到敌人**。其中一批是"给自己上护盾/减伤 + 嘲讽敌人"的守护型——护盾在**空转**（它armor 起来去接根本不会飞向它的伤害）：

## C. 技能数值是否合理（回答问题 ②）

技能**数值**（伤害倍率、状态幅度、冷却、能量）**内部大体自洽**——大招伤害均值 0.78/中位 0.35（159 个纯功能大招无直伤，符合辅助/坦克定位），伤害倍率 top 是 02/惠惠/一方通行/御坂/明日香（都是高 DPS 定位，合理）。但有两处真问题 + 一处数据层问题：

### C1. 🟡 P2 — 0.45「近上限」永久被动失衡簇（17 条）

被动 ratio 型幅度绝大多数落在 **0.08–0.25**（337 条），但有 **17 条突跳到 0.45**（正好卡在实战 ~0.5 上限下沿），个别角色**叠两条 0.45**：

`10440 晓美焰 slow.45`、`66899 四宫辉夜 haste.45`、`5088 葛城美里 haste.45`、`3576 白井黑子 haste.45+critRateUp.45`、`10630 折原临也 slow.45`、`7998 大道寺知世 critRateUp.45(全队)`、`64717 大场奈奈 slow.45`、`64712 爱城华恋 critRateUp.45`、`64716 露崎真昼 critRateUp.45+haste.45`、`10570 两仪式 critRateUp.45`、`4546 卡缪 critRateUp.45+haste.45`、`10538 岚山步鸟 haste.45`、`61942 日高小春 critRateUp.45`、`66614 岩永琴子 slow.45`。

例：大道寺知世被动 = 全队 +45% 暴击率整场；折原临也 = 全体敌 −45% 速度整场（是他自己大招 30% slow 的 1.5 倍——**被动强过大招**）。同批 peer 只有 0.12。**这不是"某人该强"，是两个偶然档位**：要么这 17 条超模，要么 0.10 那档偏弱。**建议统一分档**（如 aura 常规 0.12–0.18、招牌 aura 上限 0.25），把 0.45 留给真正该爆的极少数并明确设计意图。

### C2. 🟠 底板属性异常 ~49 SSR（数据层，**非技能配置**）

工作流报「承太郎/茵蒂克斯/柊司 属性比同稀有度低 ~30%」。查 `all_cards.json` 原始 `battle_stats`：**承太郎 hp611、茵蒂克斯 hp611，而 SSR 中位是 856**；且不是个例——**49 个 SSR 落在 ~600–614 hp 的塌陷带**（冈崎朋也/达克妮斯/保登心爱/黑桐干也…）。这是**基础角色数据的管线异常**（可能是某批导入没归一化），**与技能 kit 无关**——技能倍率是对的，但这些角色因底板低，技能伤害/治疗（按 atk/sp 缩放）实际打折。**修复不在 `characterKits.ts`**，在角色数据生成侧（`backend/` 的 battle_stats 归一）。列为独立数据债。

### C3. 🟢 个别倍率倒挂（低）

`35687 芸芸` skill1 spRatio 1.4 == 大招 spRatio 1.4（冷却基础技=大招伤害，无成长感）；`10902 黑桐干也` skill1 atkRatio 2.0（超模板 skill1 带 ~1.0–1.4，且他是明写的非战斗人员）。零星，随 B1/A3 一起顺手调即可。

## D. 效果是否契合角色幻想 + 定位（问题 ①②的机制层）

引擎实装没问题，但有一批**机制没抓住角色的定义性能力**（"名对、数值对、但效果不是这个角色"）：

**招牌能力缺失/错配**：
- `35607 菜月昴` 被动直接叫「死亡回归」却只给自身 HoT+defUp——**Return by Death**（死亡回溯）的幻想完全没体现（引擎有 `revive`，可做"首次阵亡时复活"）。
- `71337 玛奇玛` 是「支配之恶魔」，kit 纯控制却挂 striker 定位（无处决/爆发）——效果对、**role 标错**。
- `137906 玛琪娜` 是六魔侯**火魔法**专家，kit 是纯控制 + 白值伤害，**零火/灼烧/dot**。
- `16817 梦梦` 招牌是**植物心灵感应**，kit 却借了**金色之暗(Yami)**的"变形武器"gimmick。
- `46582 相麻堇` 的 kit 用了 **Reset 能力**，但 Reset 属于春埼美空、记忆保持属浅井圭——**张冠李戴**。
- `2354 优子(Yoko)` 是**狙击手**，整套 kit 却是**螺旋/钻头**（那是卡米那/西蒙的招牌）。
- `10609 立华奏` 纯盾+奶**零输出**，丢了她最标志的 **Hand Sonic** 主动刃。
- `10612 仲村由理` desc 明写"手枪+白刃战"，kit 却当成她**并不属于**的 Girls Dead Monster 团员来做。

**定位（role）错配（9 条）**，典型：
- `46464 艾莉丝` 纯剑士（狂犬）却挂 **arcane** + skill1 带 spRatio → 应 striker 去 sp。
- `19041 由比滨结衣` 挂 **controller** 却是纯奶（无一控制）。
- `27235 安原绘麻` 挂 **guardian** 却是专职奶。
- `84 草薙素子`（挂 guardian，实为 controller，效果反而贴合 controller）、`1667 柊镜`（挂 controller，实为处决 striker）、`4 古河渚`（guardian→support）。

这些**多数只需改 `role` 字段**（定位单一真相源 `CHARACTER_KITS[id].role`），少数（Subaru/立华奏/玛琪娜）值得补一个招牌 effect。
