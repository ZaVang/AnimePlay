## Phase 1: 功能体验

### 首次印象与上手路径
- 进家园即 `runSettle()` 结算离线收益，`>0.5h` 才弹窗、零碎静默入账——防打断做得好。
- ops 面板信息层次清晰：舒适度 → 可用 KP → 三设施卡 → 入住名单，投资决策链完整。可用 KP 独立成 `kp-strip` 强调，玩家知道自己有多少弹药。

### 核心流程逐步走查（家园经营手感）
1. **设施升级目标感**：三卡各有 Lv 徽章 + `设施加成 +X%` + `下一级 +N 单位/h · C KP` + 升级按钮，"花多少换多少"透明。**目标感成立**。
2. **KP 花得值不值**：`nextDelta`（升级后每小时增量）直接展示在按钮上方，且与结算同源——玩家能算清 ROI。**这是本轮最大加分项**。
3. **离线收益结算仪式**：弹窗列出经验/好感/知识点/舒适度四行 + 挂机时长 + 角色数。基础到位，但见 Phase2 的口径不一致坑。
4. **无底 sink（SD-T5）**：Lv.99 极高上限 + `120×1.4^(level-1)` 指数成本，第 N 级严格 > 第 N-1 级，成型账号 KP 有持续去处。**根因 E 解决**。

### 边界情况与错误处理（发现两处坑）
- 🟡 **空家园升级陷阱**：`placedCards` 为空时 `computeIdleYield` 因 `count===0` 直接返回全 0，于是 `nextDelta=0`，但 `affordable` 仍可能为 true（只看 `knowledgePoints >= cost`）——**没有入住角色时点升级会白花 KP、产出纹丝不动**。升级按钮的 affordable 判据应叠加「有入住角色 且 nextDelta>0」，或对空家园给出明确禁用文案。
- 🟢 升级失败仅 `addLog('升级失败：知识点不足或已满级')`——但按钮在不 affordable 时已 `:disabled`，此分支实际很难触发，属冗余保险（可接受）。
- ✅ 升级前 `settleHomestead()` 结清 + `profile.spend` 失败即 return + 满级 Infinity 挡住——货币/存档路径无漏洞。

## Phase 2: 审美品味

### 配色与视觉层次
- 全走皮肤语义令牌（`--c-accent/-soft`、`--c-ink/-2/-3`、`--c-line`），无 text-white 压浅底、无动态拼接色类，合规。
- `ops-card-main`（舒适度卡）双层渐变 + 底部三色描边（accent→highlight→info），是全面板视觉焦点，合理——舒适度是核心指标。
- 设施卡 Lv 徽章用 `accent-soft` 底 + `accent` 字，与主色一致，识别度好。

### 字体与排版
- 层级清晰：`ops-kicker`(.75rem/700) 标签 → `strong`(1.35rem/产出值) → `small`(.72rem/加成说明)，韵律感在。
- 🟢 Lv.1 设施文案「设施加成 基础」（`pctText(0)` 返回"基础"）对新手不传达"升级能涨"——首次进家园三卡全"基础"略显死板，可改为「+0%（升级 +8%/级）」之类前瞻文案，把成长轴的诱惑提前露出来。

### 间距与信息密度
- `facility-grid` 桌面单列、平板/窄屏三列、超窄单列——响应式档位合理，密度舒适。
- 舒适度卡 `min-height:132px` 给了呼吸感，不拥挤。

### 动效与过渡
- 🟡 **升级"投资兑现"仪式感缺失**：点升级成功后除了一行日志 + 数字静默跳变，**没有任何视觉反馈**（无金额飞出、无 Lv 徽章跳动、无产出数字滚动/高亮）。经营系统的核心快感就是"投进去→肉眼看见回报"，当前是"点一下、KP 少了、+X%变了"，缺少那一下"值了"的正反馈。这是本轮最影响手感的审美缺口。
- ✅ `resident-pill` hover 有 translateY + 描边 + 阴影过渡，入住名单交互反馈到位。

### 整体视觉性格
- 动森风广场 + ops 运营侧栏的双栏结构，性格清晰（"生活基地 + 经营面板"）。设施卡接入后，运营侧栏从"3 个死标签"变成"可操作的投资台"，性格更完整了。

## Phase 3: 产品想象力

### "如果能 XXX 就太好了"
1. 💡 **设施升级的"回本时长"提示**：在 `nextDelta` 旁标「约 X 小时挂机回本」（cost ÷ 该设施每小时 KP 增量）——把 ROI 从"每小时多产多少"翻译成玩家真正在意的"多久赚回这笔 KP"，决策更爽。（超范围，backlog）
2. 💡 **"一键升到买得起的最高级"批量升级**：无底 sink 后期单点点击疲劳，给个 shift+点击或长按连升。（超范围）
3. 💡 **comfort 来源可视化**：当前 comfort 只显总数 + 软加成%，但玩家不知道"再多穿哪件装备能跨过下一个 +1% 台阶"。给一条"距下一档 +1% 还差 N 点"的进度提示。（与 SD-T2 comfort 来源迁移天然衔接，backlog）

### 可以删掉的东西
- 🟢 `onUpgradeFacility` 里的 `addLog('升级失败…')` 分支——按钮已 `:disabled`，此路几乎不可达，是防御性冗余。留着无害，但若追求简洁可删（低优）。

### "啊哈时刻"分析
- 本轮把"啊哈时刻"从**无**（设施是死标签）拉到了"点升级→下一级 +N 是真的→挂机回来果然多了"。但这个啊哈现在**被弱反馈稀释**了：玩家要靠脑补/翻日志才确认"值了"。补上 Phase2 说的升级正反馈动效，能让啊哈来得更早更强。

## Phase 4: 一致性与对比

### 跨口径一致性（本轮命脉，逐点复核）
- ✅ **设施乘区口径同源**：UI `hourlyYield`/`nextHourlyYield` 与 `settleHomestead` 均 `computeIdleYield(..., facilityStore.getLevels())`，同函数同入参——预览==实战，无欺骗。**守住了**。
- 🟡 **comfort 展示口径不一致（新体验坑）**：ops 面板用 `comfortBonusText`（显示"全产出 +X%"，即软加成语义）；但**离线收益弹窗第 4 行显示 `{{ settleResult.comfort }}` 原始点数**（如"舒适度 40"）。同一个 comfort 在两处一个显%一个显点数，玩家在弹窗看到"舒适度 40"无法对应到面板的"+4%"。建议弹窗也显软加成%（或"舒适度 40（全产出+4%）"），口径统一。
- ✅ 存档三处（schema/migrations/persistence）+ store + 测试五处域 key `facility` 命名一致；v17 迁移旧档补 Lv.1（非 Lv.0，避免归零回归）——eval 已复跑测试全绿。

### 与同类产品对比
- 对标放置类（AFK 类、《最强蜗牛》基建）：设施可升级 + 指数成本 + 挂机回报 = 标准放置经营骨架，本轮已具备。差距在**回报可视化仪式**（放置类通常有满溢动画、离线收益的数字滚动/宝箱开启感）——AnimePlay 当前离线弹窗是静态列表，缺"开箱"快感。
- 对标 comfort 类软加成（动森"幸福度"）：动森会明确告诉你"再放 X 件家具解锁 Y"，AnimePlay 的 comfort 目前只给结果值，缺"如何再涨"的引导（见 Phase3 建议 3）。

## Prioritized Recommendations

### 🔴 Critical（阻止发布）
- 无。本轮 SD-T1 + SD-T5 已真实现，验收命令全绿（eval 复跑 745/745 测试、type-check/build/security 全过），无回归、无阻断。

### 🟡 Important（应尽快修复）
1. **[SD-T1] 空家园升级陷阱**：无入住角色时 `nextDelta=0` 但升级按钮仍 affordable，点击白花 KP。`facilityRows` 的 `affordable` 应叠加 `placedCards.length>0 && nextDelta>0` 条件，或对空家园禁用升级并提示"先入住角色"。
2. **[SD-T1] comfort 展示口径不一致**：离线弹窗显 `comfort` 原始点数，ops 面板显软加成%。弹窗改显软加成%（或点数+%并列），与面板 `comfortBonusText` 统一，避免玩家困惑同一指标两种口径。
3. **[SD-T1] 升级投资兑现反馈缺失**：升级成功仅一行日志，无视觉正反馈。补一个轻量反馈（Lv 徽章跳动 / 产出数字高亮滚动 / KP 扣减动画之一），把"值了"的正反馈即时给到——这是家园经营手感的临门一脚。

### 🟢 Nice-to-have（锦上添花）
4. **[SD-T1] Lv.1 前瞻文案**：`pctText(0)` 的"基础"改为透出下一级涨幅（如"+0%（升级 +8%/级）"），首次进家园即让成长轴可见。
5. **[超范围] 删冗余失败日志分支**：`onUpgradeFacility` 的 addLog 失败分支在按钮 disabled 下几乎不可达（低优，留着无害）。

### 💡 Feature Idea（backlog，不进本轮）
6. **[超范围] 设施升级"回本时长"提示**：cost ÷ 每小时 KP 增量 → "约 X 小时挂机回本"，ROI 翻译成玩家语言。
7. **[超范围] comfort"距下一档还差 N 点"进度提示**：与第 2 轮 SD-T2（comfort 来源迁到设施）天然衔接。
8. **[超范围] 一键升到买得起的最高级**：无底 sink 后期减少点击疲劳。
