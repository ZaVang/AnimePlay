## Executive Summary

**总评分：7.8 / 10**（前两轮 T1/T2/T3/T2-E 落地扎实，工程口径与显形债都补齐；本轮 T4 是 S15 收官切片，也是「爬塔挫败感」这条最容易劝退玩家的负面情绪的正面回应）。

- **功能体验（8/10）**：T2 家具 v20 存档三处同改、口径经 comfort 轴同源汇入、T2-E 把羁绊/家具 delta 搬进决策页，都做对了。塔掉落现状（50% × 层段稀有度 × 随机槽）机制干净但**纯随机**——玩家爬 10 层可能一件想要的槽/稀有度都不出，这是 P3-3 的真痛点，T4 正是解药。
- **审美品味（7.5/10）**：家具面板/羁绊徽章走语义令牌、delta 预览克制。但**掉落反馈仍是「一行日志 + 结算面板一件」**，保底/碎片进度若不显形，会重蹈 comfort 死数值反模式（玩家不知道自己「离保底还差几层」）。
- **产品想象力（7.5/10）**：T4 是把「爬塔」从「拉老虎机」变成「有奔头的定向获取」的关键。**保底解决「运气差」，碎片解决「想要的拿不到」**——两者情绪价值不同，选哪个决定 T4 到底缓不缓解挫败。本报告主张 **优先碎片定向兑换**（详见 Phase 3）。

## Phase 1: 功能体验

### 首次印象与上手路径（回归复审，无阻断）
- `/homestead` hub 五面板（home/characters/squad/explore/battle）切换顺畅；家具兑换 + 摆放/收纳、入住羁绊显形（T2-E 已进 `HomesteadManageModal` 头部）均可达，决策页不再「方向盘装后备箱」。
- 爬塔路径（explore → SquadBattleView → completeFloor）：通层 → 50% 掉一件 → 日志 `🎁 通层掉落：[R] 木刀！` + 结算面板展示。链路本身无摩擦。

### 核心流程逐步走查 —— T4 痛点定位（本轮重点）
1. **通层掉落是纯随机三重门**：`rollTowerDrop` 先掷 50%，命中再随机槽（weapon/armor/supporter 各 1/3），稀有度由层段固定。玩家想要「supporter 槽的 SSR」时，即使层段对了，也要过「命中(50%) × 该槽(33%)」两道随机——**期望要 ~6 次通层才见一次该槽**，而 SSR 层段只有 16-30 共 15 层且每层只能推进一次（重复挑战低层不掉落，见 `pve.completeFloor` floor 守卫）。**这是结构性挫败：想定向补一个槽，纯随机几乎给不了。**
2. **毕业玩家掉落彻底断流**：到塔顶（999）后 `completeFloor` 返 `false` 不再掉落，只剩扫荡（`sweepFloor` 独立路径，**明确不掉装备**，userStore.ts:857）。毕业玩家想要的 UR 特定件若没抽到，**再无正当获取路径**（只能 24000 KP 定向兑换，昂贵）。这正是「碎片定向兑换」要补的洞。
3. **重复件的唯一出口是分解/强化燃料**：`dismantleValueForRarity` 回收 KP + 强化吃同 defId 游离件。重复 R/SR 件已经有意义，但**「差一件想要的却出一堆不想要的」的转化通道缺失**——碎片兑换可把「重复的不想要件」经分解 KP 或独立碎片计数转成「定向想要件」，闭合这个循环。

### 边界情况与错误处理（现状健康）
- `completeFloor` 已区分 `{completed, drop}` 三态，防顶层/篡改刷取；扫荡走独立路径不碰 `completeFloor`。T4 无论走保底还是碎片，**都必须挂在 `completed===true` 的推进分支内**（复用天然防刷低层的守卫），别新开一条绕过守卫的发放路径。

## Phase 2: 审美品味（回归复审 + T4 显形前瞻）

- **配色 / 层次**：家具面板、羁绊徽章、delta 预览均语义令牌（accent/surface/ink/line），grep 无 `text-white`/动态拼色类违规（eval 已核）。视觉一致性守住。
- **T4 显形前瞻（本轮成败命门，与 T3 同型教训）**：保底/碎片若**只在后台记数、不在 UI 显形**，就是又一个 comfort 死数值。玩家爬塔时看不到「距离保底还差 N 层」「碎片攒了 X/Y」，就感受不到「有奔头」——挫败缓解等于没做。**必须像 T2-E 羁绊 chip 一样，在爬塔/结算/背包处显形保底进度条或碎片计数徽章**（accent 令牌、就近取整、满即高亮）。
- **动效**：非本轮必需；保底触发瞬间给一次 chip 微亮/结算面板高亮「保底触发！」文案，顺手则加，否则 backlog。

## Phase 3: 产品想象力 —— T4 该做哪个（本轮拍板建议）

### 「如果能 XXX 就太好了」

1. **💡 优先做「碎片定向兑换」而非纯 pity（本轮主张）**。理由：**两者解决的情绪不同**——
   - **pity 保底**解决「运气差」：连 N 次没出某稀有度后强制给。但塔掉落稀有度是**层段固定的**（16-30 恒 SSR），玩家不缺 SSR 数量，缺的是**特定槽/特定件**。纯稀有度 pity 收益有限。
   - **碎片兑换**解决「想要的拿不到」：把「重复的不想要件」→ 碎片 → 定向换「想要的那一件」。**直接闭合 Phase1 定位的三个洞**（定向补槽难、毕业断流、重复件转化）。对本产品「968 番真实资产 + 名梗装备目录」的收集向定位，碎片让「翻目录挑心仪件」成为可达目标，比 pity 更贴产品灵魂。
   - **结论**：若二选一，选碎片。若行有余力，pity 可做**轻量版**——「连续 M 次通层未掉落任何件（50% 空掷）→ 第 M+1 次必掉」，只保底「有没有」不保底「是不是想要的」，成本低、缓解「白爬一路」的空手挫败，与碎片互补不重叠。

2. **💡 碎片来源复用现有成功点，不新造玩法**：分解重复件产碎片（`dismantleValueForRarity` 旁加碎片产出）+ 扫荡/周委托发碎片（`sweepFloor`/commission 已有埋点）。**毕业玩家靠扫荡攒碎片换 UR**，正好补 Phase1 洞 #2 的断流。

3. **💡 碎片按稀有度分档、兑换定向到「槽+稀有度」或具体 defId**：让玩家用碎片精确换想要的那件（如 200 SSR 碎片换任意 SSR，或指定 defId 溢价）。这才是「定向」的本义。

### 可以删掉 / 不做的东西（至少 1 个）
- **不做「多档稀有度 pity 表 + 每档独立计数持久化」**：那是 gacha 式复杂保底，与塔「层段固定稀有度」模型不匹配，存档字段膨胀、测试组合爆炸。**塔的稀有度已被层段决定，别在稀有度维度做重型 pity。** 若做 pity 只做「空掷保底」单计数。

### 「啊哈时刻」
- T4 的啊哈 = **「我攒的碎片终于够换那件心仪的 supporter 了」** 或 **「连爬 8 层没出，这次保底必给」**。啊哈来得早晚取决于**显形**——进度可见，玩家才会为了「再爬两层触发保底 / 再攒 30 碎片」持续爬塔。这是把塔从「刷完就腻」变成「有目标地刷」的杠杆。

## Phase 4: 一致性与对比

### 跨切片一致性
- **口径铁律（与 T2/T3 同源要求一脉相承）**：T4 若做保底，pity 计数**若持久化必须复用 v20 bump，绝不升 v21**（Scout C-1 / gen_status 已钉死，本 Sprint 唯一 bump 已用于 furniture）。碎片若走货币则**只走 `profile.spend/earn`**（架构铁律），若走独立计数则新域仿 furniture/facility 域三处同改 + 往返测试。
- **engine 纯净**：pity/碎片的**判定逻辑放 engine 纯函数 + 注入 RNG + 注入计数**（仿 `rollTowerDrop`），别在 store 里塞 `Math.random`。计数状态在 store，纯函数只接收数值——这样特征测试能断言「pity 边界：连 N 次未出后第 N+1 次必出」可复现。
- **发放守卫**：保底/碎片发放**必须挂 `completeFloor` 的 `completed===true` 分支内**（复用防刷低层守卫），扫荡发碎片走 `sweepFloor.ok` 分支，别新开绕过守卫的路径。

### 与同类产品对比
- **PCR / 原神装备本**：都是「定向刷本 + 碎片/材料兑换」而非纯随机掉落——纯随机掉落是十年前页游模型，玩家早已期待「可预期的定向获取」。T4 走碎片兑换是与现代收集向手游对齐的正确方向。
- **本产品差异化**：碎片兑换定向到「名梗装备目录」（死亡笔记/AT力场/四次元口袋…），让「攒碎片换心仪梗件」比通用材料更有收集乐趣——这是本产品该放大的独特资产。

## Prioritized Recommendations

### 🔴 Critical（本轮 S15-T4 必须落地，否则空跑）
- **[S15-T4] 真落地定向掉落缓解机制，不得只做回归确认**（历史教训 SA-T6/SF-T8：指派切片是 in-scope，严禁误判「新范围」跳过）。二选一由 Planner 拍板，**体验官强烈建议优先碎片定向兑换**（见 Phase 3 理由：直接闭合定向补槽难/毕业断流/重复件转化三洞；pity 可做轻量「空掷保底」互补）。
- **[S15-T4] 判定走 engine 纯函数 + 注入 RNG + 注入计数**（仿 `engine/squad/drops.ts` `rollTowerDrop`），特征测试断言 pity 边界（连 N 次未出后第 N+1 次必出）/ 碎片兑换（够数发货、不够拒绝、走 profile 或独立计数往返）；掉落序列 RNG 可复现。

### 🟡 Important（本轮做透的深度守则）
- **[S15-T4] 保底/碎片进度必须 UI 显形**（与 T3 羁绊显形、T2-E 决策页显形同型命门）：爬塔/结算/背包处显「距保底还差 N 层」或「碎片 X/Y」进度，accent 令牌、就近取整、满即高亮。**不显形 = comfort 死数值反模式 = 挫败没缓解 = 白做。**
- **[S15-T4] 版本纪律**：pity 计数若持久化**复用 v20，绝不升 v21**（本 Sprint 唯一 bump 已用于 furniture，Scout C-1）；若碎片走独立域则仿 facility/furniture 三处同改 + 往返 + 脏档归一测试；若碎片走货币则**只走 `profile.spend/earn`**。
- **[S15-T4] 发放挂 `completed===true` 分支**：复用 `completeFloor` 防刷低层守卫，扫荡发碎片走 `sweepFloor.ok`，别新开绕过守卫的路径（防顶层/篡改刷取，延续 completeFloor 三态设计）。

### 🟢 Nice-to-have（锦上添花）
- **[S15-T4] 碎片来源复用现有成功点**：分解重复件产碎片 + 扫荡/周委托发碎片（毕业玩家靠扫荡攒碎片换 UR，补断流），不新造玩法埋点。
- **[S15-T4] 保底触发瞬间给一次结算面板高亮 / chip 微亮**（「保底触发！」文案），顺手则加否则 backlog。
- **[S15-T4] 碎片兑换定向到名梗具体 defId**（而非只按稀有度），放大「攒碎片换心仪梗件」的收集乐趣。

### 💡 Feature Idea（backlog，不进本轮）
- 多档稀有度 pity 表 / gacha 式重型保底（**明确不做**——与塔层段固定稀有度模型不匹配）。
- 塔专属掉落图鉴 / 碎片商店主题轮换 / 装备心愿单（点亮想要件→碎片够时提示）。
- 广场家具可视化拖拽摆放（S15-T2 backlog 延续，独立固定槽位常量，WALKABLE_ZONES 不动）。
