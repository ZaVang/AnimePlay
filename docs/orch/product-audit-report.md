# Product Experience Audit Report — Iteration 1

## Executive Summary

总评分：7.1/10。当前家园页已经有可爱的角色漫步、离线收益弹窗和入住管理，第一眼是成立的；但它更像一个展示场景，而不是二游里会让玩家每天回来的“基地”。装备系统完成了背包、兑换、配装和数值预览，但装备之间的差异仍主要是数值大小，缺少能影响家园/养成循环的“效果感”。

## Phase 1: 功能体验

- 首次印象与上手路径：登录后进家园可以看到广场、角色漫步和“管理入住”。路径短，但玩家很难立即理解“为什么要回来”，因为收益只在弹窗里出现，常驻页面没有运营状态、产率、加成来源。
- 核心流程走查：入住角色 → 离线结算 → 经验/好感/KP 入账是闭环；装备 → 战力提升也闭环。但家园和装备之间没有明显关系，玩家不会想到“给入住角色配装备能让家园更好”。
- 边界情况与错误处理：未登录、无入住角色、无装备都有空态。当前空态可用但较静态；满入住、重复入住由 store 防住。

## Phase 2: 审美品味

- 配色与视觉层次：场景本身有风格，但头部下面缺少数值/设施层，导致大面积主视觉承载了全部信息。
- 字体与排版：现有排版稳定，家园 header + scene 简洁；但关键产出指标藏在文案或弹窗里，不利于扫描。
- 间距与信息密度：家园页偏空，适合加一个紧凑的运营仪表带，而不是堆更多说明文字。
- 动效与过渡：角色 rAF 漫步有生命感；装备 UI 主要是静态列表，缺少“效果标签”让道具有辨识度。
- 整体视觉性格：家园已经有“桌宠广场”人格，但还未成为“基地 hub”。

## Phase 3: 产品想象力

- 如果能看到“舒适度 / 产率 / 设施”就太好了：玩家进入家园第一屏就知道当前基地每小时产什么、装备效果在不在生效。
- 如果装备有家园词条就太好了：武器偏训练效率、防具偏休息舒适、支援偏资料产出，让配装不只服务挑战塔。
- 如果入住角色卡片显示装备/羁绊状态就太好了：场景里的角色和系统成长建立连接。
- 可以删掉的东西：不需要新建复杂家具摆放编辑器；当前阶段它会消耗大量 UI/存档成本，收益低于“运营仪表 + 装备效果”。
- 啊哈时刻：现在是“角色会在家园走动”。更强的啊哈应是“我给主推配了装备，她在家园也会让基地变好”。

## Phase 4: 一致性与对比

- 跨视图一致性：养成页能看装备数值，家园页看不到装备贡献；这是最大的断点。
- 与同类产品对比：二游家园/基地常把角色放置、收益、恢复/羁绊和装饰舒适度绑定。AnimePlay 当前只有放置收益的一半，需要补常驻反馈和装备联动。

## Prioritized Recommendations

- Critical：无阻塞发布级缺陷。
- Important：在家园页加入运营仪表，显示舒适度、每小时经验/好感/KP、加成来源。
- Important：给装备目录扩容，并让装备带真实家园效果，至少影响离线收益计算而不是只显示文案。
- Nice-to-have：入住角色卡片显示等级、好感、已装备数量和效果标签。
- Feature Idea：后续可做家具/房间主题/派驻岗位，但本轮不升存档，先用派生设施模型落地。
