## 项目概述

本项目是一个围绕动画题材的"收集 + 抽卡 + 组卡 + 多种玩法"一体化前端应用。玩家可以：
- 抽取动画卡与角色卡，构建收藏与卡组
- 进入"宅理论战"，与 AI 进行回合制卡牌辩论对战
- 进入基地 hub，统一管理家园离线收益、角色养成/装备、5 人编队、探索挑战塔与横板半自动战斗
- 玩"猜角色"像素化小游戏
- 自由切换 6 套全局配色主题

前端基于 Vue 3 + Pinia + TailwindCSS 构建。整体布局由 `App.vue` 提供：顶部头部区（登录/玩家信息）、左侧导航栏、右侧主内容区（路由视图）。

> 各系统的机制细节见同目录专题文档：`抽卡系统.md`、`战斗系统.md`、`挑战塔系统.md`、`角色养成系统.md`、`猜角色游戏.md`、`主题系统.md`。
> 各页面功能完善度与已知缺陷见 `项目审计报告-2026-06-12.md`。

## 已实现的核心功能
- 登录/登出与基础玩家信息展示（用户名、等级、知识点、双抽卡券数量）
  - ⚠️ 登出按钮当前无点击事件（已知 bug）
- 抽卡系统（动画/角色）：卡池、商店、抽卡历史图表、结果弹窗与概率说明、每日 UP 轮换
- 收藏页：动画/角色收藏筛选、重复卡一键分解、虚拟化网格、卡组管理入口
- 宅理论战：选卡组开局、对战 UI、战斗日志与议题偏向条、出牌/防御/结束回合、AI 决策、辩论对话特效
  - ⚠️ 对局结算未闭环（打完无胜负界面/无奖励）
- 基地 hub：家园入住与离线收益、角色等级/好感、装备、5 人 HR/UR 编队、挑战塔探索与横板半自动战斗入口统一
- 角色养成：等级/五维加点、好感里程碑、装备槽/背包，养成数值反哺挑战塔
- 挑战塔：5v5 横板半自动战斗，普攻/小技能自动释放，能量满后可手动或自动释放大招
- 猜角色游戏：像素化 4 难度档、稀有度加权计分
- 设置页：6 套全局主题、战斗速度、AI 档案选择、议题偏向条样式切换（音频设置占位）

## 全局布局（`App.vue`）

导航（7 项）：主页、抽卡系统、卡牌收藏、宅理论战、基地 hub、🎮小游戏、设置。

```
+----------------------------------------------------------------------------------+
| Header:  Logo「动画宅的自我修养」 | 登录/玩家信息（用户名, Lv., 动画券/角色券, 登出）     |
+----------------------------------------------------------------------------------+
| Sidebar (nav)            | Main Content (RouterView)                            |
| - 主页                   |                                                      |
| - 抽卡系统               |                                                      |
| - 卡牌收藏               |  根据路由切换到对应页面                              |
| - 宅理论战               |                                                      |
| - 基地 hub               |                                                      |
| - 🎮 小游戏              |                                                      |
| - 设置                   |                                                      |
+--------------------------+------------------------------------------------------+
```

路由表（`router/index.ts`）：`/`·`/gacha`·`/collections`·`/battle`·`/homestead`·`/minigames`·`/minigames/:gameId`·`/settings`，除主页外均懒加载。旧 `/squad-battle` 重定向到 `/homestead?tab=explore`，旧 `/nurture` 重定向到 `/homestead?tab=characters`，旧 `/guess` 重定向到 `/minigames`。无路由守卫，未登录可进入所有页面（各页自行渲染"请先登录"空状态）。

## 页面与 ASCII 线框图

### 主页（`HomeView.vue`）
含玩家状态、观看队列（独占一行）、下方三列：活动日志 / 收藏预览 / 观看统计。

```
+--------------------------------- Home -----------------------------------------+
| PlayerStatus（等级/经验条/知识点/双券/卡组数）                                   |
|--------------------------------------------------------------------------------|
| WatchQueue（3 槽位追番队列，倒计时收获经验）                                     |
|--------------------------------------------------------------------------------|
| ActivityLog (left)      | CollectionPreview (mid)   | ViewingStats (right)      |
|-------------------------+---------------------------+---------------------------|
```

### 抽卡系统（`GachaView.vue`）
支持"动画抽卡/角色抽卡"切换；上方页签切换"卡池/商店/历史"；抽卡后弹出结果，概率说明单独弹窗。

```
+------------------------------ 抽卡系统（Gacha） --------------------------------+
| [ 动画抽卡 ] [ 角色抽卡 ]                                                       |
|--------------------------------------------------------------------------------|
| Tabs: [ 卡池 ] [ 商店 ] [ 历史 ]                                               |
|--------------------------------------------------------------------------------|
| if 卡池:                                                                        |
|  ├─ UpBanner（当日 UP 的 UR/HR + 轮换倒计时 + 保底说明）                        |
|  ├─ 资源展示：动画/角色券数量                                                   |
|  └─ 抽卡按钮：单抽 / 十连  （概率一览 链接）                                   |
|                                                                                |
| if 商店: GachaShop（券/药水/知识点包等道具；卡牌走图鉴定向解锁）                |
| if 历史: GachaHistory（稀有度占比柱状图 + 抽卡明细列表）                        |
|                                                                                |
| 弹窗： GachaResultModal（抽卡结果，标 new/duplicate）/ GachaRatesModal（概率详情） |
+--------------------------------------------------------------------------------+
```

### 收藏（`CollectionsView.vue`）
三页签：动画收藏/角色收藏/我的卡组；支持名称/稀有度/标签筛选、重复卡一键分解；卡片网格（>100 张虚拟化）+ 详情弹窗。

```
+---------------------------- 收藏（Collections） ---------------------------------+
| Tabs: [ 动画收藏 ] [ 角色收藏 ] [ 我的卡组 ]                                     |
|--------------------------------------------------------------------------------|
| Filters（动画/角色页签时显示）：                                                |
|  - 名称搜索 / 稀有度 /（动画）标签 / 一键分解重复卡 / 启用虚拟化开关            |
|--------------------------------------------------------------------------------|
| Content：                                                                       |
|  if 动画/角色收藏: 网格 AnimeCard/CharacterCard * N（点击 → CardDetailModal）   |
|  if 我的卡组: DeckManager（DeckList 列表 → DeckEditor 双栏编辑：左收藏右卡组）  |
|                                                                                |
| 弹窗： CardDetailModal（卡面详情、技能效果、登场作品、持有数、单张分解）        |
+--------------------------------------------------------------------------------+
```

### 宅理论战（`BattleView.vue`）
两阶段：选卡组（`DeckSelector`/随机开局）→ 战斗界面。战斗界面含：对手场、中央区（左日志 / 中偏向条+对线区 / 右操作）、我方场。

```
+------------------------------ 战斗（Battle） ------------------------------------+
| if 阶段=选卡组：                                                                |
|  └─ DeckSelector（已存卡组 / 随机开局 / AI 档案选择 / 规则详解弹窗）            |
|--------------------------------------------------------------------------------|
| if 阶段=战斗：                                                                  |
|  对手场（PlayerField: playerB, isOpponent — 含角色阵容、声望/TP、手牌背面）     |
|--------------------------------------------------------------------------------|
|  中央区：                                                                       |
|   ┌───────────────┬───────────────────────────┬──────────────────────────────┐ |
|   │ BattleLog     │ TopicBiasBar + ClashZone  │ 结束回合 / 规则 / 退出战斗  │ |
|   └───────────────┴───────────────────────────┴──────────────────────────────┘ |
|--------------------------------------------------------------------------------|
|  我方场（PlayerField: playerA — 角色阵容、手牌正面、出牌交互）                  |
+--------------------------------------------------------------------------------+
```

说明：
- 防御阶段且当前主动玩家为 AI（`playerB`）时，右侧出现"跳过防御"按钮（`BattleController.skipTurn()`）。
- 相关组件：`BattleLog`、`TopicBiasBar`、`ClashZone`、`BattleDialogueManager`（辩论气泡/「异议！」特效）、`CharacterActionModal`（角色技能）、`InteractionManager`（看手牌/选牌等复杂交互）。

### 基地 hub / 家园综合系统（`HomesteadHubView.vue`）
基地 hub 是家园、角色、编队、探索、战斗的统一入口。`HomesteadView` 负责家园角色走动与离线收益，`NurtureView` 保留完整养成/配装操作，`SquadBattleView` 负责横板半自动战斗与结算。

```
+------------------------------ 基地 hub（Homestead） -----------------------------+
| 标题「基地 hub」                                                                |
|--------------------------------------------------------------------------------|
| Tabs: [ 家园 ] [ 角色 ] [ 编队 ] [ 探索 ] [ 战斗 ]                              |
|--------------------------------------------------------------------------------|
| 家园：角色入住/漫步地图/离线收益结算                                            |
| 角色：角色列表 + 五维基础/加点/装备/最终值 + 装备槽 + 小队战技能摘要            |
|      下方内嵌 NurtureView，提供等级、好感、背包、配装和里程碑操作               |
| 编队：3 支预设小队；每队 5 站位（前/前/中/中/后）；展示战力、资格、技能摘要     |
| 探索：当前塔层、历史最高、敌方 5 人阵容、战力/难度、角色经验/KP/装备奖励预览    |
| 战斗：进入 SquadBattleView；5v5 横板半自动战斗，自动小技能，手动/自动大招       |
|                                                                                |
| 兼容：/squad-battle -> /homestead?tab=explore；/nurture -> /homestead?tab=characters |
+--------------------------------------------------------------------------------+
```

### 角色养成（`HomesteadHubView.vue` + `NurtureView.vue`）
从基地 hub 的"角色"面板进入。顶部先给当前角色的五维、装备和小队战技能摘要，下方复用 `NurtureView` 完成等级、好感、配装、背包和里程碑操作。

```
+------------------------------ 角色面板（Characters） ----------------------------+
| 左侧角色列表（稀有度/等级）                                                     |
|--------------------------------------------------------------------------------|
| 角色摘要：立绘 | 稀有度 | 等级 | 好感称号 | 战力                             |
|--------------------------------------------------------------------------------|
| 五维表：HP / ATK / DEF / SP / SPD，每项显示基础 / 加点 / 装备 / 最终值          |
|--------------------------------------------------------------------------------|
| 装备槽：武器 / 防具 / 支援，展示装备名、稀有度和加成                            |
|--------------------------------------------------------------------------------|
| 小队战技能：普攻 / 小技能1 / 小技能2 / 被动 / 大招                              |
|--------------------------------------------------------------------------------|
| NurtureView：等级、好感、背包、配装、里程碑领取                                 |
+--------------------------------------------------------------------------------+
```

### 🎭 猜角色（`GuessView.vue` + `GuessCharacter.vue`）
像素化猜角色小游戏，4 次机会，每错一次图片更清晰。

```
+------------------------------ 猜角色（Guess） ----------------------------------+
| 进度条（4 阶段）                                  剩余 N 次机会   [R 重开]      |
|--------------------------------------------------------------------------------|
| 难度标签（极难 8×8 / 困难 16×16 / 中等 32×32 / 简单 原图）                     |
|--------------------------------------------------------------------------------|
|                      ┌────────────────────┐                                    |
|                      │  像素化角色立绘     │                                    |
|                      └────────────────────┘                                    |
|--------------------------------------------------------------------------------|
| [ 输入角色名字... ]  [ 猜! ]   （支持模糊匹配、大小写、简繁体）                 |
| 结果： 命中展示角色信息 + 得分；最高分 / 最近记录（⚠️ 不持久化，刷新清零）      |
+--------------------------------------------------------------------------------+
```

### 设置（`SettingsView.vue` + `SettingsModal.vue`）
以页面形式承载 `SettingsModal`，含显示/音频页签。

```
+------------------------------ 设置（Settings） ----------------------------------+
| SettingsModal                                                                   |
|  ├─ Tabs: [ 显示设置 ] [ 音频设置 ]                                            |
|  ├─ 显示设置：                                                                  |
|  │   - 全局主题（6 套：暖调浅色/Flip7青绿/深色霓虹/海洋蓝/樱花粉/森林绿）      |
|  │   - 战斗速度（正常/快速/瞬间）                                              |
|  │   - AI 对手（档案下拉）                                                     |
|  │   - 议题偏向条样式（gradient/cyber/elegant）                                |
|  └─ 音频设置：占位（"开发中"）                                                  |
+--------------------------------------------------------------------------------+
```

说明：
- 全局主题由 `stores/theme.ts` 驱动（CSS 变量换肤，详见 `主题系统.md`），与 `settings.ts` 中遗留的 `uiTheme`（经典/赛博朋克/简约，已无 UI 入口）是两套独立体系——后者为死配置。
