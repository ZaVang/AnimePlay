# 部署 · 阿里云全流程（个人备案 + 全大陆栈）

> 目标形态：**一台便宜大陆 VPS 跑逻辑 + cron + 个人主页，图片全放阿里云 OSS/CDN**，
> 主域名备案一次、子域名全覆盖。本机不下 583MB 图片，3M 小带宽也不卡。
>
> 配套改动（已在仓库就绪）：
> - 前端 `VITE_IMAGE_BASE_URL`：图片源开关（不设=同源本地托管，行为不变；设了=指向 OSS/CDN）。见 `frontend-vue/.env.example`、`frontend-vue/src/utils/assetUrl.ts`。
> - 部署脚本 `deploy/vps-setup.sh`：新增 `IMAGE_BASE_URL`（跳过图片下载 + 前端指向图床）、多站 Caddy（`/etc/caddy/sites/*.caddy`）、`REPO_URL` 镜像覆盖。

## 依赖关系（为什么是这个顺序）

```
域名实名 ──等≈3天──┐
                   ├──→ ICP备案(1~3周, 期间域名不能访问) ──→ 解析上线 + 绑 CDN 域名
买大陆ECS(领备案码)─┘
        ↑ 这两步可同时做         ⏳ 备案审核这几周里, 把服务器环境/前端/图片上传 OSS 全部备好, 不浪费
```

---

## Phase 0 — 账号 & 域名（立刻能做）

- [ ] 注册/登录**阿里云账号**，完成**账号实名认证**（个人，App 刷脸）
- [ ] 在阿里云买**域名**（`.com`/`.cn` 等；同账号买，备案最省事）
- [ ] 给域名做**域名实名认证**，实名信息**必须与身份证完全一致**
- [ ] ⏳ **实名后等约 3 天**入库工信部，否则提交备案被驳回

## Phase 1 — 买服务器 + 领备案码（与 Phase 0 并行）

- [ ] 买 **ECS 经济型 e，2核2G，约 99元/年（续费同价）**
  - ✅ 必须：**包年包月（≥3 个月）** + **有公网带宽** + **中国内地地域** → 才能领备案服务码
  - ❌ 别选：按量付费 / 香港·海外地域（这两种领不到备案码、也备不了案）
- [ ] 实例开好后在阿里云备案系统**申请备案服务码**（免费，1 台 ECS 给 5 个）

> 依据：每个阿里云 ECS（包月≥3 个月、有公网带宽、内地地域）可申请 5 个免费备案服务码。
> 99元/年 经济型 e 是包年=12 个月，满足条件。

## Phase 2 — ICP 备案（1~3 周，核心等待期）

- [ ] 阿里云 App / ICP 代备案系统，主体类型选**「个人」**
- [ ] 填**主体信息**（身份证）+ **网站信息**（域名 / 网站名 / 服务内容）
  - ⚠️ **千万别勾**经营性、企业性质、或新闻/医疗/视听等需前置审批的内容（个人只能做非经营性、通常 1 域名）
- [ ] **App 刷脸 + 拍照核验**（活体认证 + 本人核验照；多数省份已**免幕布**）
- [ ] 上传身份证正反面 → 提交 → 阿里云**初审 1~2 工作日**（可能电话核对）
- [ ] **工信部短信核验**：初审过后收到短信，**24 小时内**回复
- [ ] **管局审核**（最长 20 工作日，多数省份几天）→ 拿到 **ICP 备案号**
- [ ] ⚠️ 这期间域名解析到大陆机器会显示「未备案」，所以**先别正式解析**，用审核期做下面的准备

## Phase 3 —（等备案时）预先把上线准备做完

- [ ] 服务器装环境：跑 `deploy/vps-setup.sh`（见下方命令）
  - ⚠️ **大陆机拉 GitHub 慢/不稳**：用 `REPO_URL=https://gitee.com/你/AnimePlay.git` 走镜像；图片走 OSS 后本机不再从 GitHub Release 拉 583MB
- [ ] 每个服务一个 **systemd 常驻**（`Restart=always`，开机自启），分配独立端口（:8080 / :5002 / …）
- [ ] 配 **cron / systemd timer** 跑定时任务（本地电脑从此不用开机）

## Phase 4 — OSS + CDN 图床（bucket 可提前建，绑 CDN 域名要等备案）

- [ ] **开通 OSS**，建 bucket（华东/华北等**大陆地域**），读权限设**公共读**
- [ ] 用 **ossutil** 从本地把 `data/images`（583MB）**直接传到 OSS**
      （别走服务器中转；保持 `data/images/<type>/...` 的目录结构）
- [ ] **开通 CDN**，加速域名填 **`img.你域名.com`**（子域名，自动覆盖在主域名备案下，**不用单独备案**），回源指向 OSS
- [ ] 部署时把 **`IMAGE_BASE_URL=https://img.你域名.com`** 传给脚本（前端构建即指向图床）
- [ ] ⚠️ OSS/CDN **下行流量按量**：量大就买**流量包**更便宜

> 换图片域名需重新 `npm run build`（地址在构建期烘焙）。卡图/缩略图按 id 实时拼接、随构建生效；
> 仅极少数持久化了绝对路径的字段（AI 生成角色头像）在「换域名」后需重生成——首次部署无此问题。

## Phase 5 — 收尾合规

- [ ] **ICP 备案号挂网站底部**，链接到 `https://beian.miit.gov.cn`
- [ ] **公安联网备案**：ICP 号下来后 **30 天内**，去 `https://beian.mps.gov.cn` 注册提交，拿公安备案号也挂底部

## 一键部署命令（备案通过后执行）

```bash
# SSH 登录大陆服务器，root 运行。把域名 A 记录先解析到本机公网 IP。
DOMAIN=play.你域名.com \
IMAGE_BASE_URL=https://img.你域名.com \
REPO_URL=https://gitee.com/你/AnimePlay.git \
bash <(curl -fsSL https://raw.githubusercontent.com/ZaVang/AnimePlay/main/deploy/vps-setup.sh)
```

- `IMAGE_BASE_URL` 设了 → 跳过 583MB 图片下载，前端图片指向 OSS/CDN，本机只跑逻辑（3M 带宽够）。
- 不设 `IMAGE_BASE_URL` → 退回「本机下图片、同源托管」的老行为（香港单机适用）。
- 控制台安全组先放行 **TCP 80 / 443**。

## 同机多站规划

| 服务 | 端口 | 域名 | 怎么加 |
|---|---|---|---|
| AnimePlay | :8080 | `play.你域名.com` | 本脚本（写 `sites/animeplay.caddy`） |
| 游戏2 | :5002 | `game2.你域名.com` | 丢 `sites/game2.caddy` + 一个 systemd 服务 |
| 个人主页（静态） | — | `home.你域名.com` 或 `你域名.com` | 丢 `sites/home.caddy`（`root` + `file_server`） |
| 图床 | — | `img.你域名.com` | 阿里云 CDN 接管，不在 Caddy 里 |

加站示例（`/etc/caddy/sites/` 下新建文件后 `systemctl reload caddy`，本脚本重跑不覆盖它们）：

```caddyfile
# /etc/caddy/sites/home.caddy
home.你域名.com { root * /var/www/homepage; file_server }
# /etc/caddy/sites/game2.caddy
game2.你域名.com { encode gzip; reverse_proxy 127.0.0.1:5002 }
```

> 所有子域名共用 Phase 2 那**一个备案**。

## 年成本估算

| 项 | 费用 |
|---|---|
| 域名 | ~¥30–60/年（`.com` 首年常更便宜） |
| ECS 经济型 e 2核2G | **~¥99/年（续费同价）** |
| OSS 存储（583MB） | ~¥0.几/月 |
| CDN 流量 | 按量，小范围朋友玩 ~几块/月（可买流量包） |
| ICP + 公安备案 | **免费** |
| **合计** | **约 ¥150–200/年起步** |

## 顺序口诀

**域名实名（等3天）+ 买 ECS 领备案码 → 备案（等3周，期间装环境+传图到OSS）→ 备案过了解析上线 + 绑 CDN 域名 → 30 天内补公安备案。**

> 价格/政策随阿里云促销与各省管局规则浮动，下单与备案前以官方页面实时信息为准。
