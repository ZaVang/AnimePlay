# 挑战塔 / 小队战斗系统

> 入口：`/homestead?tab=explore`（基地 hub 的探索面板）与 `/homestead?tab=battle`（战斗面板）。旧 `/squad-battle` 保留为兼容入口，会重定向到基地 hub 的探索面板。

挑战塔是 S13 基地闭环的战力验证玩法：家园离线收益和角色养成提升等级/五维，装备提供战斗与家园词条，玩家编成 5 人 HR/UR 小队后进入横板半自动战斗。胜利推进塔层，并把角色经验、装备掉落机会和知识点回流到养成与基地循环。

## 基地 hub 路线

1. `家园`：入住角色漫步并结算离线经验、好感、知识点。
2. `角色`：查看等级、好感、五维、装备槽和小队战技能。
3. `编队`：配置 5 人挑战塔小队，检查站位、战力和技能摘要。
4. `探索`：预览当前塔层、敌方 5 人阵容、战力、难度与奖励。
5. `战斗`：进入 D4 横板半自动战斗，结算后奖励回流。

## 出战条件

- 每队固定 5 个站位：前排、前排、中排、中排、后排。
- 只允许已拥有的 HR/UR 角色进入挑战塔。
- 角色必须拥有完整小队战技能包：普攻、两个小技能、被动、大招。
- 编队与塔进度由 `pve` 域持久化；视图只做编辑与展示。

## 战斗规则

- 战斗使用 `engine/squad/timedBattle` 事件流驱动，视图负责播放。
- 普攻、两个小技能按冷却自动释放。
- 能量满 1000 后释放大招；玩家可在自动/手动大招间切换。
- SPD 影响行动速度；暴击、护盾、控制、治疗、复活等效果来自装备或技能配置。
- 胜负由 5v5 单位实际 HP、能量、状态与技能效果结算，不再使用旧的前排轮流普攻回合模型。

## 战斗属性

每个角色有 5 项战斗属性：

| 属性 | 含义 |
|---|---|
| HP | 生命值 |
| ATK | 攻击力 |
| DEF | 防御力 |
| SP | 技能强度 |
| SPD | 行动速度 |

实战属性由 `generateBattleStats(base, statPoints, equipBonus)` 生成：

| 来源 | 说明 |
|---|---|
| `base` | 角色基础 `battle_stats` |
| `statPoints` | 角色升级随机加点，来自现行养成数据 |
| `equipBonus` | 当前装备提供的五维加成 |

角色面板、编队面板和战斗入口必须使用同一套口径，避免展示战力与实战战力不一致。

## 塔层与敌人

- 5 层一个循环，敌方 HR/UR 配置逐层提高，第 5 层为 5 UR 守关。
- 每完整通过 5 层，后续敌方全属性获得额外强化。
- 敌方优先从真实 HR/UR 角色池生成；数据不足时才使用负数 ID 的 AI 占位。
- 探索面板展示当前层敌方名称、战力、难度、成员与奖励预览。

## 奖励

只有胜利并推进当前层时发放奖励：

| 奖励 | 说明 |
|---|---|
| 角色经验 | 发给参战角色，进入现行等级/五维成长路径 |
| 知识点 | 走 `profile.earn` 入账 |
| 装备掉落 | 通层分支注入 RNG 判定，命中后进入装备背包 |

失败不会推进楼层，也不会发放角色经验、知识点或装备。

## 关键文件

- `frontend-vue/src/views/HomesteadHubView.vue` — 基地 hub、探索/编队/战斗入口整合
- `frontend-vue/src/views/SquadBattleView.vue` — 横板半自动战斗播放、结算与选人弹窗
- `frontend-vue/src/components/battle/squad/` — 战场、角色条、大招按钮、日志、结算组件
- `frontend-vue/src/engine/squad/` — 纯战斗规则、敌人生成、奖励、资格校验
- `frontend-vue/src/stores/pve.ts` — 小队与塔进度
- `frontend-vue/src/stores/equipment.ts` — 装备背包、配装与战力加成解析
