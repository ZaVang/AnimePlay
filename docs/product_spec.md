# Product Spec: 战术终端 2.0 - 高易用性纯净中文化

## Goal
在保留工业战术风（Terminal Aesthetic）的基础上，进化至高度可读且易用的纯中文界面。消除视觉噪音，确保核心数据与磁盘存储方案（JSON）完美同步。

## Key Architecture
1. **中文字体革命**: 全局启用高清晰度无衬线字体（Noto Sans SC / Inter）。弃用模糊的等宽字体作为正文显示，仅将其保留在底层日志中。
2. **高对比度色彩**: 提升文字亮度。使用 `text-white` 或 `text-cyan-400` 作为主信息色，搭配暗色背景，消除灰色字体的“泥泞感”。
3. **品牌本地化**: 移除所有 `ANIMEPLAY_SYS` 等英文标识。界面左上角及核心组件头部统一使用纯中文命名。
4. **全量数据协调器**: 前端 Store 层级需具备全量数据接管能力。加载 `Aririgi.json` 时，自动映射 `state`, `collection`, `viewingStats` 等所有核心数据，不再仅限于等级同步。

## UI/UX Refinement (v2.0)
5. **移除双语标注**: 移除所有 `用户 // USER` 格式的英文后缀。界面应像成熟的商业软件一样简洁有力。
6. **动态扫描线减负**: 扫描线透明度设为极低（1% 或 2%），或者仅在特定交互（如载入）时出现，防止长期阅读导致视疲劳。
7. **界面对齐机制**: 强化网格对齐，确保所有 Data Slate 组件在视觉上严丝合缝，体现终端的精密感。
